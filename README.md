# Retail Sales Visualization Dashboard

## About the Project
This project uses Python, Pandas, and Matplotlib to analyze retail sales data and create a dashboard with four charts.

## Features
- Analyze monthly revenue and expenses.
- Calculate total profit.
- Visualize monthly revenue trends.
- Compare revenue and expenses.
- Analyze orders and revenue using a scatter plot.
- Save the dashboard as an image.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files
- `retail_sales.csv` – Sales dataset
- `retail_visualization.py` – Python script
- `retail_sales_dashboard.png` – Dashboard image
- `README.md` – Project documentation

## How to Run
1. Install the required libraries:

   ```bash
   pip install pandas matplotlib
   ```

2. Keep the CSV file and Python script in the same folder.
3. Run the program:

   ```bash
   python retail_visualization.py
   ```

4. The dashboard will be displayed and saved as `retail_sales_dashboard.png`.
